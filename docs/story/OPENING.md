# OPENING BEAT SHEET: First 5 Minutes (B-001..B-030)

Covers the first 5 minutes (`0:00` to `5:00`, 300 s) on `STREAM` (Tier 1, 16x6 grid, 60 s tide period, 5 clean tides to clear).
- Tide 1: `0:00-1:00` | Tide 2: `1:00-2:00` | Tide 3: `2:00-3:00` | Tide 4: `3:00-4:00` | Tide 5: `4:00-5:00` (Tier clears at `5:00`).
- **Silt Payout Rule**: Per `GAME_DESIGN.md` section 6, each clean tide on Tier 1 pays `+1 Silt` (`1 * tier#`). There is **no separate bonus Silt reward** for clearing a tier; thus after Tide 5 ends cleanly at `5:00`, the player receives the standard `+1 Silt` clean-tide payout (bringing cumulative Silt to `5`) and unlocks the `RIVER` transition.
- **Note on `GAME_DESIGN.md` Section 8 Conflict**: `GAME_DESIGN.md` section 8 lists a 6-minute script (`2:30` for `1/5` tides, `4:30` for Tide 3 breach, `5:30` for tier clear) that conflicts with the 60 s $\times$ 5 = 5:00 `STREAM` parameters in `GAME_DESIGN.md` section 3 and `src/data/balance.js`. Per P1 instructions, this file follows the strict 5:00 (5 $\times$ 60 s) schedule; the conflict is documented in `docs/story/P1_6_AUDIT.md`.
